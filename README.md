# Profile Website

A one-page personal portfolio built with plain HTML, CSS and JavaScript. It works on phones,
has a dark mode, and fades each section in as you scroll.

## Files

- `index.html`: the page content. Edit your name, bio, skills, projects and links here.
- `style.css`: colors, fonts and layout. Change `--accent` at the top to pick a new theme color.
- `script.js`: the dark-mode toggle, scroll animations and footer year.

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish free with GitHub Pages

1. Merge this branch into `main`.
2. In the repo, go to **Settings → Pages**.
3. Under **Source**, pick **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Your site will be live at `https://nmuha0272-cmyk.github.io/work/`.
